# Aurelia OS — Native Build Guide (Android APK + iOS)

Each of the 8 apps (`00-central-hub` through `07-distribution-affiliate-engine`) ships as:

1. **Progressive Web App (PWA)** — installable from Chrome/Safari, works offline
2. **Capacitor native wrapper** — build `.apk` (Android) or `.app`/`.ipa` (iOS) locally

---

## Option 1: PWA / WebApp (No Install Required)

Every app is already a PWA with a service worker and web app manifest.

**Android (Chrome):**
1. Open the app URL in Chrome
2. Tap the three-dot menu → "Add to Home Screen"
3. The app installs as a standalone icon on your home screen

**iOS (Safari):**
1. Open the app URL in Safari
2. Tap the Share button → "Add to Home Screen"
3. The app installs as a standalone icon

Apps are accessible via the **Download Center** in the Central Hub (`00-central-hub` on port `5173`).

## Option 2: Android APK (Sideloadable)

### Prerequisites (install once on your machine)

- **JDK 17+** — [Adoptium Temurin](https://adoptium.net/) or [Oracle JDK](https://www.oracle.com/java/)
- **Android Studio** — [Download](https://developer.android.com/studio)
- **Android SDK** — install via Android Studio SDK Manager (API 34+, build-tools)
- **Node.js 20+** — [Download](https://nodejs.org/)

### Per-App Build Steps (run in each app folder)

```bash
# 1. Navigate to the app folder
cd /workspace/04-ctl-encrypted-relay   # or any other app folder

# 2. Install Capacitor Android platform
npx cap add android

# 3. Sync web assets into the native project
npx cap sync android

# 4. Open in Android Studio
npx cap open android

# 5. In Android Studio: Build → Generate Signed Bundle / APK
#    Select APK → choose release build → create keystore if needed

# 6. Alternative: CLI build
cd android && ./gradlew assembleRelease

# 7. The unsigned APK will be at:
#    android/app/build/outputs/apk/release/app-release-unsigned.apk

# 8. Sideload to your Android device
adb install android/app/build/outputs/apk/release/app-release-unsigned.apk
```

## Option 3: iOS Native (Xcode)

### Prerequisites (install once on your Mac)

- **Xcode 15+** — [App Store](https://apps.apple.com/us/app/xcode/id497799835)
- **iOS Simulator or physical iOS device**
- **Apple Developer account** (for device deploy / App Store)

### Per-App Build Steps

```bash
# 1. Navigate to the app folder
cd /workspace/04-ctl-encrypted-relay

# 2. Install Capacitor iOS platform
npx cap add ios

# 3. Sync web assets
npx cap sync ios

# 4. Open in Xcode
npx cap open ios

# 5. In Xcode: Product → Archive → Distribute App
#    Or run on simulator: Product → Run
```

## Option 4: Automatic CI Builds (GitHub Actions)

A GitHub Actions workflow (`.github/workflows/build-native-apps.yml`) automatically builds:

- **Android APKs** on every push to `cline/4tqt8m3y` or `main`
- **iOS projects** on macOS runners

APK artifacts are available for download from the GitHub Actions run page for 30 days.

## PWA Features Included

All 8 apps include:

| Feature | Description |
|:---|:---|
| **Service Worker** | Offline caching, background sync |
| **Web App Manifest** | Installable app icon, standalone display |
| **iOS Meta Tags** | `apple-mobile-web-app-capable`, touch icon, status bar |
| **Auto Updates** | `registerType: 'autoUpdate'` — new versions load on next visit |
| **Cross-App Deep Links** | `#ctl=` and `#vault=` hash fragments for inter-app handoff |
